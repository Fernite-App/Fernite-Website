# Fernite — Website

The official landing page for **Fernite**, a free, open-source Minecraft launcher forked from the Modrinth App. No ads, no telemetry, no account required. Just play the game.

> **Live site:** https://fernite.vercel.app

---

## What is Fernite?

Fernite is a fork of [modrinth/theseus](https://github.com/modrinth/theseus) that strips out everything that shouldn't be there — tracking, ads, and mandatory account login — and adds offline/cracked account support. This repository contains the **static marketing website**, not the launcher application itself.

The launcher source is at: https://github.com/Fernite-App/Fernite
