// What's different

No bullshit. Just play the game.

Offline & Cracked Accounts
Play without a Mojang account. Enter any username and jump straight into the game — no login walls, no purchase verification.
Zero Telemetry
Every analytics call, usage ping, and tracking beacon has been stripped out. Fernite never phones home. Your sessions are your own.
Ad-Free Interface
No sponsored placements, no promoted projects, no banners. The UI is yours — clean, uncluttered, built for players not advertisers.
Full Modrinth Integration
Browse, install, and update mods, modpacks, resource packs, and shaders directly from Modrinth's full catalog — everything intact.
Profile Management
Separate profiles for each modpack or version. Switch between survival, modded, and minigame setups instantly without conflicts.
Open Source
Every line of code is public. Fork it, audit it, build on it. Fernite is a community project — not a product with a roadmap designed around revenue.

"Software should respect the person running it — not harvest them."

Fernite started as a personal fork, built out of frustration with launchers that treat players as inventory. Modrinth built something genuinely good — and then bolted tracking and ads onto it.

This fork takes that foundation, cuts everything that shouldn't be there, and adds offline account support so the launcher works for everyone. No agenda, no monetization, no bullshit.

It's distributed under the same license as the upstream project. The source is on GitHub. Read it, run it, fork it.
